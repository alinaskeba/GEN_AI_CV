# HW1 — Normalizing Flows

[RealNVP.ipynb](RealNVP.ipynb) presents multi-scale RealNVP on MNIST and Fashion-MNIST. The other Homework 1 topics are covered in [VAE.ipynb](VAE.ipynb) and [GAN.ipynb](GAN.ipynb). The [results index](results/README.md) links to all saved experiments.

## Architecture and experiments

The model uses affine coupling layers, checkerboard and channel masks, squeeze operations and a multi-scale latent split. New images are generated by sampling the standard normal latent variables and reversing the flow.

Four configurations were trained from scratch on each dataset with the same seed, split, optimizer and 40-epoch budget:

| Architecture | Hidden channels | Couplings per stage | Learned mixing matrices |
|---|---:|---:|---:|
| Compact baseline | 32 | 4 | 0 |
| Wide baseline | 64 | 6 | 0 |
| Sparse mixing | 64 | 6 | 2 |
| Dense mixing | 64 | 6 | 12 |

Compact versus wide measures overall capacity because both width and depth change. The wide variants compare the frequency of learned invertible channel mixing.

## Evaluation and results

Each checkpoint was selected by validation bits per dimension (bpd). The validation winner for each dataset was evaluated on the official test set. Dense mixing achieved the best validation bpd on both datasets; test bpd was approximately 1.3133 for MNIST and 3.1680 for Fashion-MNIST. Some samples still have ambiguous shapes or broken strokes.

Lower bpd is better. It is a uniform-dequantization bound, not exact discrete likelihood. Samples at temperature 0.7 provide a visual comparison with temperature 1; changing temperature changes the sampling distribution rather than improving likelihood. Generated samples are independent examples, not reconstructions of the displayed originals.

## Saved artifacts

`results/full/<run-id>/` contains validation comparisons, test metrics, environment details, learning curves and generation panels. Each experiment also has a configuration, training history and best-checkpoint sample grid. The final panels compare real images with every experiment and the validation-selected model.

## Reproduction

Install the [root requirements](../requirements.txt), start the kernel in `HW1/`, and run cells in order with `SMOKE_TEST=False`. The full sweep trains eight models for 40 epochs each. New executions create new result directories.

Raw data are cached under `../.local/hw1/data/`; checkpoints are saved under `../.local/hw1/checkpoints/<run-id>/`. Neither is included in Git.
